# Forma 0.7.2

Maintenance release for verification of the complete native update workflow from 0.7.1: download, signed archive validation, installation, and relaunch through Forma's built-in updater.

This release uses the same application code as 0.7.1. Translation and writing features are unchanged. It retains the corrected GitHub feed resolution, signed feeds and archives, application identity, and production iCloud configuration.

Public updates do not require a GitHub token. In Forma 0.7.1, use Settings → Updates → Check for Updates… and follow the installation prompt.

Users of 0.7.0 need a one-time manual installation from the DMG because that version's feed resolver cannot read the GitHub update feed correctly.

Requires Apple Silicon and macOS 26+. ChatGPT processing uses your connected account's eligible plan usage and existing limits.

# Forma 0.7.0

The first public release of Forma: a native macOS translator and writing assistant.

Requires **Apple Silicon and macOS 26+**. Download the DMG, open it, and drag Forma to Applications.

- Translate, proofread, and rewrite with your connected ChatGPT account and eligible plan usage.
- Open the quick popup with double Command-C or a custom shortcut; copy results or replace captured text.
- Choose tone, explore contextual alternatives, and keep a personal dictionary and Custom Prompt Rules.
- Keep local history, optionally sync dictionary/history/rules through private iCloud, and use Apple Translation for supported on-device language pairs.
- Public update downloads use this repository and do not need a GitHub access token.

Connect ChatGPT and grant Accessibility permission separately on each Mac. Existing ChatGPT plan limits apply. iCloud sync requires explicit opt-in in Settings → Sync.

Document processing, additional AI providers, API-key connections, and local models are planned and are not included in this release. iCloud checks have covered two isolated clients on one Mac; two physical Macs and migration from older development releases still need wider verification.

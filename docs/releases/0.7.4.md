# Forma 0.7.4

More useful contextual alternatives for words and phrases:

- Requests up to eight distinct alternatives instead of three. If fewer than four usable choices arrive, one additional request tries to expand the list without repeats. Some selections may still have fewer natural alternatives.
- Selected phrases, clauses and sentence fragments are rephrased as a whole, with changes to vocabulary and structure. Explicit alternatives also allow local rephrasing of a proofreading result while preserving its tone.
- Replacements are applied only to the selected occurrence. Surrounding text is preserved, and duplicate or unchanged choices are removed.
- A wider, scrollable alternatives list makes longer suggestions easier to read. Useful initial choices are retained if the additional request fails.

The application and DMG are Developer ID signed and notarized by Apple. Public updates do not require a GitHub token.

Update from 0.7.1 or later through Settings → Updates → Check for Updates…, or download the DMG. Version 0.7.0 needs a one-time manual installation because its feed resolver cannot read GitHub's update feed correctly.

Requires Apple Silicon and macOS 26+. Automated regression tests cover selection replacement and request handling; live model suggestion quality has not been separately evaluated for this release.

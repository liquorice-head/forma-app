# Forma 0.7.3

The public app no longer shows the Private repository access section or GitHub token controls in Settings → Updates.

Public builds always check for updates anonymously and do not read saved private-release GitHub tokens. Internal staging builds retain their private-repository controls. Existing credentials are not deleted.

Update from 0.7.1 or later through Settings → Updates → Check for Updates…, or download the DMG. Version 0.7.0 needs a one-time manual installation because its feed resolver cannot read GitHub's update feed correctly.

Requires Apple Silicon and macOS 26+.

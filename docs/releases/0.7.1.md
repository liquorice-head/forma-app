# Forma 0.7.1

Fixes checking for updates from GitHub Releases, including anonymous checks without a GitHub token.

Sparkle requests appcast feeds as RSS. GitHub's asset API responds to that request with JSON metadata, which was incorrectly passed to Sparkle as a signed XML feed in 0.7.0. Forma now resolves the GitHub download redirect before handing the feed to Sparkle. Feed and archive signatures remain required. GitHub credentials, when used for private releases, are restricted to the repository's API requests and are not sent to the feed CDN.

**For users of 0.7.0:** install this release manually using the DMG once, because the old updater cannot read GitHub's feed correctly. Then use Settings → Updates → Check for Updates… normally. Public releases do not require a GitHub token.

Requires Apple Silicon and macOS 26+. Existing ChatGPT connections, local data, and Accessibility settings use the same application identity.
